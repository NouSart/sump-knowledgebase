# 第二课：第一次复现

先从固定版本开始，不把不断变化的 main 与历史教程混用。

1. 阅读 [版本说明](../版本记录/2026-10-26-主线149451db/README.md)。
2. 下载该页链接的源码 ZIP，并解压到新建学习目录。
3. 找到同时有 go.work、protocol、service、mcp 的文件夹，这才是项目根目录。
4. 阅读 [从源码到可复现验证](../核心技术/2026-10-26-149451db/09-从源码到可复现验证.md)，一次只运行一个练习。

不熟悉命令窗口时，可以先完成阅读和流程模拟。想从界面入手，阅读 [前端与可视化操作](../核心技术/2026-10-26-149451db/07-前端与可视化操作.md)。

看到网页能够打开，只说明入口能运行；测试通过只证明对应场景。真实模型、真实设备和公网部署需要各自的验证。

记录复现结果时写清：源码版本、运行环境、操作、预期与实际结果。不要提交密钥、个人文件或本机运行日志。
