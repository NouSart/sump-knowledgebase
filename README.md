# SUMP 学习知识库

面向零基础读者，围绕 SUMP 的独立服务架构，解释代码怎样组织、消息怎样传递、工具怎样并行工作，以及如何验证实际行为。

本仓库由 **xml-nya-meow** 维护，是独立学习资料，非 SUMP 官方文档。项目来源：[SUMP](https://github.com/NouSart/sump)。

- [核心技术十课](核心技术/2026-10-26-149451db/README.md)：Go、WebSocket、配置、模型工具、记忆、并发、前端、权限边界与验证。

## 阅读方式

每次学习一个问题：先看通俗解释，再看流程图和源码位置，最后按需做练习。不要求先背完术语，也不要求一开始运行整个项目。

首版发布基础课程和基于提交 `149451dbf9ec953006da7c1926c336cfd9da0633` 的十课。内容是固定版本的源码分析与教学，不保证等同于当前主线。后续专题在完成核查后单独发布。

## 事实与验证

- 源码存在不等于测试已经运行。
- 受理回执不等于工具已经完成。
- 本地夹具通过不等于所有外部产品都兼容。
- 模拟案例不是生产日志。

请勿在 issue 或提交中包含 API Key、令牌、私钥、个人目录或未脱敏日志。
